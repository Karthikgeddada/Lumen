## The thesis in five lines

1. Private credit is a ~$2T asset class whose ops teams still re-key borrower PDFs into Excel.
2. Incumbent monitoring software (Chronograph, Allvue, iLevel) is a data-entry portal with workflow bolted on — humans still type the numbers.
3. LLMs can now read those documents with page/sheet/cell-level accuracy — but funds won't trust prose, they trust **traceable numbers with human review**.
4. Nobody owns the AI-native cell: mid-market funds ($500M–5B AUM), extraction-to-covenant dashboard, deployable in a day.
5. The window is ~18–24 months before incumbents bolt on AI. Speed and trust posture are the whole game.
